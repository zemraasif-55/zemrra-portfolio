# Zemra Asif — Portfolio (Black + Gold Redesign)

## Run locally
1. Extract this folder.
2. Keep `index.html`, `style.css`, `script.js`, `Resume.pdf`, and the `images/` folder together.
3. Open `index.html` in a browser. For a local server, use VS Code Live Server.

## Main files
- `index.html` — page content and sections
- `style.css` — black-and-gold design, responsive layout and animations
- `script.js` — mobile navigation, active navigation, reveal effects and rotating role text
- `images/` — existing project previews and hero image
- `Resume.pdf` — existing resume linked from the page

## Before publishing
- Check that your resume is current.
- Replace certificate names with the exact titles/links of your certificates if available.
- Confirm all project links and contact details are the ones you want publicly displayed.
- Font Awesome and Google Fonts are loaded from CDNs, so those external assets require an internet connection.


## Animation pack
The portfolio includes a staggered hero entrance, gentle ambient gold movement,
floating availability badge, scroll-line reveal, animated skill bars, staggered
scroll reveals, animated navigation underline, and refined card/button hover
feedback. It respects the user's `prefers-reduced-motion` accessibility setting.
